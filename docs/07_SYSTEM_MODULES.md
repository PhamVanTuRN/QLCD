# SYSTEM MODULES

Các module chính của phần mềm Quản lý điểm danh.

## 1. Dashboard
- Tổng quan hệ thống
- Thống kê sự kiện trong ngày
- Hiệu suất điểm danh trực tiếp.

## 2. Event Management
- Quản lý danh sách sự kiện (CRUD).
- Phân công địa điểm (Event-Location mapping).

## 3. Location Management (Địa điểm / Hội trường)
- Quản lý các phòng/hội trường tổ chức sự kiện.
- Sức chứa, loại phòng.

## 4. Device Management
- Danh mục thiết bị.
- Mapping thiết bị vào Location.
- Quản lý trạng thái (online/offline).

## 5. Attendance Configuration
- Cấu hình Attendance Rules.
- Cấu hình Attendance Windows.

## 6. Attendance Log Management
- Tiếp nhận Raw Logs (API).
- Xem lịch sử quét thẻ/khuôn mặt thô.
- Không cho phép chỉnh sửa.

## 7. Attendance Result Management
- Quản lý kết quả tính toán cuối cùng.
- Công cụ tính toán lại (Recalculation).
- Chức năng Manual Override (ghi đè kết quả thủ công).

## 8. Participant Management
- Quản lý danh sách người tham gia (Persons).
- Import người tham gia từ file Excel hoặc từ API.

## 9. Reporting
- Báo cáo thống kê tổng hợp.
- Xuất Excel/PDF.

## 10. Integration
- Module đồng bộ HLĐT (Huấn luyện Đào tạo).
- Webhook/Cronjob.

## 11. System Administration
- Cài đặt cấu hình chung.
- Backup/Restore.

## 12. User / Role / Permission
- Quản lý tài khoản (Users).
- Quản lý phòng ban (Organization Units).
- Quản lý Role và Permission Matrix.
